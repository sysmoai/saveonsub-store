# DeepSeek ফ্রি নাকি API? বাংলাদেশের জন্য সহজ গাইড

> তথ্য ১২ নভেম্বর ২০২৬ তারিখে [DeepSeek-এর API দামের পেজ](https://api-docs.deepseek.com/quick_start/pricing) থেকে পড়া। দাম বদলায়, ব্যবহারের আগে দেখে নিন।

## সংক্ষেপে উত্তর

DeepSeek-এর সাইটে চ্যাট অ্যাপ ও ডাউনলোড আছে, কিন্তু **কোনো পেইড কনজিউমার প্ল্যান দেখানো নেই**। চ্যাট হিসেবে ব্যবহার করতে আলাদা সাবস্ক্রিপশন কেনার দরকার সাধারণত পড়ে না। পেইড ব্যবহার মানে **API**, যেখানে ব্যালেন্স টপ-আপ করে টোকেন হিসাবে খরচ হয়।

## API-এর অফিসিয়াল দাম (প্রতি ১ মিলিয়ন টোকেন, ডলারে)

| মডেল | ইনপুট (ক্যাশ মিস) অফ-পিক / পিক | আউটপুট অফ-পিক / পিক |
|---|---|---|
| deepseek-flash | $0.15 / $0.30 | $0.60 / $1.20 |
| deepseek-v4-pro | $0.66 / $1.32 | $1.98 / $3.96 |

## পিক আওয়ার ঢাকার সময়ে

পিক সময় সপ্তাহের কর্মদিবসে UTC ০১:০০–০৪:০০ ও ০৬:০০–১০:০০। ঢাকার সময়ে এটি **সকাল ৭টা থেকে ১০টা** এবং **দুপুর ১২টা থেকে বিকাল ৪টা**। এই সময় দাম বেশি, তাই বড় কাজ অফ-পিক সময়ে চালালে খরচ কমে।

## কার API দরকার

যারা নিজের অ্যাপ, বট বা কোডে DeepSeek জুড়তে চান, তাদের। শুধু প্রশ্ন করা, লেখা বা কোড বোঝার জন্য চ্যাট অ্যাপই যথেষ্ট।
