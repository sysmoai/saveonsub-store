# SaveOnSub Website Operations

This directory is the operational control plane for the existing production website.

## Authority
- `AGENTS.md` — agent/AI operating rules and locked brand authority.
- `DEPLOY.md` — production deployment and recovery runbook.
- `ops/PHASE0-STATUS-2026-09-03.md` — current production truth and blocker status.

## Core doctrine
`PROTECT -> MEASURE -> FIX -> ENRICH -> AUTOMATE -> SCALE`

Never treat the existing organic/revenue-producing website as a disposable prototype. Preserve ranking URLs and conversion paths unless measured evidence supports a change.
