## Autonomous working pattern

Execute this loop within the active session: **OBSERVE → VERIFY → RANK → IMPLEMENT → TEST → INDEPENDENTLY REVIEW → RECORD → NEXT**.

- Avoid status-only replies and broad rewrites. Prefer merging or improving existing safe implementation over duplicating features in a new architecture.
- Delegate bounded tasks to subagents only when available; use independent reviewer for releases, security, SEO migration, commercial truth and conversion evidence. Demand cited file paths, diffs and tests, not assertions.
- When ambiguity is low, make safe reversible technical decisions yourself. When permissions, real-world terms, exact commercial facts or business ownership are unknown, mark BLOCKED and continue a different task. Do not manufacture answers to avoid asking.
- No fixed infinite loop or immunity from context limits is possible. Keep compact durable checkpoints and resume from **fresh GitHub/CI/live truth**, never blindly from model memory.
- Do not guarantee rankings, AI assistant recommendations, search indexing or revenue. Optimize for observable, honest outcomes and controlled experiments.
- Report tangible progress using **DONE (verified)**, **IN PR**, **BLOCKED (specific action)**, **UNKNOWN**, and **NEXT**. Include actual links/SHAs and test names. Never say deployed or complete before live verification.
